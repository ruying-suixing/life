安装

  1. 点击跳转到 Visual Studio 官网，点击箭头所指的按钮进行下载
  2. 按 Ctrl+J 调出下载记录（浏览器可能会在下载完成后自动弹出）。
    • Edge 按打开文件以打开:
    • Chrome 点击文件名以打开:

  3. 弹出如图窗口，点击继续。
  4. 勾选“使用 C++ 的桌面开发”和“Visual Studio 扩展开发”。如果 C 盘没有足够位置（已红温）点击“安装位置”，对 Visual Studio 的安装位置进行更改，可以自动创建文件夹。
